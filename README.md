# Apuntes de Bases de Datos

Materiales y actividades del módulo profesional **0484: Bases de Datos**, del ciclo formativo de grado superior de **Desarrollo de Aplicaciones Multiplataforma (DAM)**. Los contenidos siguen las unidades de trabajo del módulo e incluyen explicaciones, ejemplos y actividades sobre:

- Fundamentos de bases de datos y sistemas gestores.
- Diseño conceptual con el modelo Entidad/Relación y diseño lógico con el modelo relacional.
- Transformación entre modelos, normalización e integridad de los datos.
- SQL: definición y manipulación de datos, consultas, agregaciones, subconsultas, control de permisos y transacciones.
- Programación en bases de datos, procedimientos y PL/SQL avanzado.
- Bases de datos NoSQL, Redis y MongoDB.

## Consultar los apuntes

El material se publica como sitio web estático generado a partir de *Material for MkDocs* en <https://aitor-medrano.github.io/bd>.

Este repositorio contiene las páginas HTML generadas para su publicación dentro de la rama [`gh-pages`](https://github.com/aitor-medrano/bd/tree/gh-pages). Los archivos Markdown originales de los apuntes no se publican en el repositorio.

## Peticiones y avisos de errores

Las ideas para mejorar el material y los errores detectados son bienvenidos. Puedes abrir una [issue](https://github.com/aitor-medrano/bd/issues) para:

- **Informar de un error:** incluye el enlace o nombre de la página, qué apartado contiene el problema y, si puedes, una explicación o los pasos para reproducirlo.
- **Proponer una mejora o pedir contenido:** describe qué tema, ejemplo o explicación te gustaría que se añadiera o revisara, y por qué sería útil.

Cuanto más concreta sea la información, más fácil será valorar y atender la petición. Recuerda que las *issues* sirven para comunicar propuestas e incidencias; no implican necesariamente que se vayan a incorporar.
